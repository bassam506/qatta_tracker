# قطة استراحة الدرعية

تطبيق ويب بسيط لتتبع القطة الشهرية لأعضاء استراحة الدرعية، مبني بملف HTML واحد ومتصل بقاعدة بيانات Firebase Firestore بحيث تتزامن البيانات فورًا بين كل الأعضاء.

## المزايا
- تتبع القطة الشهرية لكل عضو (قطّ / لم يقطّ) مع إجمالي محصّل ومتوقع لكل شهر.
- إدارة قائمة الأعضاء وتواريخ مناسباتهم الخاصة (ميلاد، زواج، تخرج...).
- قائمة بالمناسبات القادمة خلال ٦٠ يوم.
- التعديل على البيانات يتطلب رمز دخول مشترك (PIN)، بينما المشاهدة متاحة للجميع.

## تفعيل الاستضافة عبر GitHub Pages
1. في المستودع: **Settings → Pages**.
2. تحت "Build and deployment" اختر **Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/ (root)`، ثم احفظ.
4. بعد دقيقة أو دقيقتين، الموقع يصير متاح على رابط بالشكل:
   `https://bassam506.github.io/qatta_tracker/`

## إعداد صلاحيات Firestore (مهم)
حاليًا قاعدة البيانات في "وضع الاختبار" (Test mode) وتنتهي صلاحيته تلقائيًا بعد ٣٠ يومًا من الإنشاء — بعدها لازم تحدّث قواعد الأمان يدويًا من:

**Firebase Console → Firestore Database → Rules**

استخدم هذه القاعدة (تسمح بالقراءة والكتابة للجميع، مناسبة لتطبيق داخلي صغير محمي برمز دخول على مستوى الواجهة فقط):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
```

**تنبيه أمني:** رمز الدخول (PIN) يحمي واجهة التطبيق فقط، وليس قاعدة البيانات على مستوى الشبكة — أي شخص يعرف بيانات مشروع Firebase تقنيًا يقدر يتجاوزه بطلب مباشر لـ Firestore API. هذا مقبول لتطبيق داخلي بين ٣٠ عضو معروفين، لكنه ليس أمانًا حقيقيًا لبيانات حساسة.

## هيكل قاعدة البيانات
- `members/{memberId}` → `{ name, occDate, occLabel }`
- `months/{YYYY-MM}` → `{ amount, payments: { memberId: true|false } }`
- `config/pin` → `{ value: "الرمز الحالي" }`
